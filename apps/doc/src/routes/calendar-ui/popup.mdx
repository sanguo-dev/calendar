# 日期格 popup

内容写在**一天的内容**里：`contentDay(day)` 返回对象时带上 `popup`，这一天就有弹层、也有绿点；返回 `null` 或没有 `popup` 字段，就没有。`popup` 选项本身只负责「怎么打开、放哪、什么语义」。

```ts
createCalendarUI(host, {
  contentDay: (day) => (hasEvent(day) ? { popup: { items: [...] } } : null),  // 内容
  // popup 选项可省略：不写就是 click + dialog + 自动定位
});
```

- 内容里的 `popup` 存在 → 这一天有 popup，日期格右上角自动出现绿点；
- `popup.items` 可以是数组，也可以是函数：函数推迟到打开弹层时才调用；
- 头部「日期 · 条数」由库自动补上，也可以用 `popup.title` 覆盖。

## 交互约定

- **绿点由库内部算**：内容里有 `popup` 就显示；
- **没有关闭按钮**：点击其他日期、点击空白处、按 `Esc`、换月、滚动或缩放页面都会关闭；
- **渲染期只判断「有没有」**：`contentDay` 每次重绘会被调用 42 次（单月），所以别在里面物化内容；重的内容写成 `items: () => [...]`，推迟到打开时才算；
- **`contentDay` 必须是同步函数**：库不负责请求数据，数据要在创建前准备好；
- **点击触发**用 `role="dialog"`，点击日期时仍然会选中日期；
- **悬停触发**用 `role="tooltip"`，只适合只读内容；移动端没有 hover，交互示例请用 `click` 或 `auto`；
- 头部「日期 · 条数」里的条数就是 `items` 的长度，所以一条数据对应数组里的一项。

## 示例一：系统 UI（点击触发）

这个示例只 import `@sanguo-dev/calendar-ui/style.css`，不写任何 popup 皮肤。`items` 每项返回 `[time, title, detail]` 三个字符串，库生成默认结构：

- `.cui__popup` 默认卡片：背景、边框、圆角、阴影、内边距；
- `.cui__popup-head`：自动显示「10 月 1 日 · 2 条」；
- `.cui__popup-title`：包含 `.cui__popup-time` 和 `.cui__popup-name`；
- `.cui__popup-detail`：detail 独占一行，12px；
- `.cui__popup-body` / `.cui__popup-item`：内容容器和每一层之间的分隔线。

```tsx
import { createSignal, onSettled } from "solid-js";
import { createCalendarUI } from "@sanguo-dev/calendar-ui";
import type { CalendarDate } from "@sanguo-dev/calendar-ui";
import "@sanguo-dev/calendar-ui/style.css";
import "./calendar-ui-popup.css";
import "./demo.css";

interface PopupEntry {
  title: string;
  detail: string;
  time: string;
}

/** 演示数据 */
const POPUPS: Record<string, readonly PopupEntry[]> = {
  "2026-10-1": [
    { title: "国庆节", detail: "10 月 1 日 - 7 日放假", time: "全天" },
    { title: "升旗仪式", detail: "广场集合，提前 10 分钟到场", time: "10:00" },
  ],
  "2026-10-8": [{ title: "寒露", detail: "早晚温差大，记得添衣", time: "节气" }],
  "2026-10-18": [{ title: "重阳节", detail: "登高、敬老", time: "农历九月初九" }],
  "2026-10-23": [{ title: "霜降", detail: "秋季最后一个节气", time: "节气" }],
  "2026-10-31": [{ title: "万圣夜", detail: "18:00 公司活动", time: "18:00" }],
};

/** 日期 -> 数据 key */
const keyOf = function (day: CalendarDate): string {
  return `${day.year}-${day.month}-${day.day}`;
};

/** 取这一天的数据 */
const entriesOf = function (day: CalendarDate): readonly PopupEntry[] {
  return POPUPS[keyOf(day)] ?? [];
};

/** 系统 UI：每项返回 [time, title, detail] 三个字符串，由库生成默认结构 */
const contentDay = function (day: CalendarDate) {
  const entries = entriesOf(day);
  return entries.length > 0
    ? { popup: { items: entries.map((entry) => [entry.time, entry.title, entry.detail] as const) } }
    : null;
};

export default function CalendarUIPopupDefault() {
  let host: HTMLDivElement | undefined;
  const [picked, setPicked] = createSignal("未选择");

  onSettled(() => {
    if (!host) return;

    const instance = createCalendarUI(host, {
      initialDate: "2026-10-01",
      onSelect: (day) => setPicked(keyOf(day)),
      popup: {
        ariaLabel: "日期详情",
      },
      contentDay,
    });

    return () => instance.destroy();
  });

  return (
    <section class="demo-popup-panel">
      <header class="demo-popup-panel-head">
        <h3>系统 UI · 点击触发</h3>
        <p>
          <code>contentDay</code> 返回 <code>{ popup: { items } }</code>，每项是
          <code>[time, title, detail]</code> 三个字符串，库生成默认的 title / detail 结构。
        </p>
      </header>
      <div ref={(el) => (host = el)} />
      <p class="demo-result">已选中：{picked()}</p>
    </section>
  );
}
```

## 示例二：自定义 UI（悬停触发）

这个示例用另一份数据、另一个 `contentDay`：`items` 是函数，打开弹层时才建 Node 数组，自己画一条时间轴，结构、类名、样式都和默认 UI 不同。库仍然自动加「日期 · 条数」头部，但头部和容器外观也由下面的 CSS 改掉。

除了数据里的字段，Node 里还可以塞完全不绑定数据的 HTML：每条 `detail` 末尾都拼一个通用署名；2026-10-1 当天给 `time` 补一个表情，并且只给「国庆节」这条的标题加一面旗子。

```tsx
import { createSignal, onSettled } from "solid-js";
import { createCalendarUI } from "@sanguo-dev/calendar-ui";
import type { CalendarDate } from "@sanguo-dev/calendar-ui";
import "@sanguo-dev/calendar-ui/style.css";
import "./calendar-ui-popup.css";
import "./calendar-ui-popup-custom.css";
import "./demo.css";

interface PopupEntry {
  title: string;
  detail: string;
  time: string;
}

/** 演示数据 */
const POPUPS: Record<string, readonly PopupEntry[]> = {
  "2026-10-1": [
    { title: "国庆节", detail: "10 月 1 日 - 7 日放假", time: "全天" },
    { title: "升旗仪式", detail: "广场集合，提前 10 分钟到场", time: "10:00" },
  ],
  "2026-10-8": [{ title: "寒露", detail: "早晚温差大，记得添衣", time: "节气" }],
  "2026-10-18": [{ title: "重阳节", detail: "登高、敬老", time: "农历九月初九" }],
  "2026-10-23": [{ title: "霜降", detail: "秋季最后一个节气", time: "节气" }],
  "2026-10-31": [{ title: "万圣夜", detail: "18:00 公司活动", time: "18:00" }],
};

/** 日期 -> 数据 key */
const keyOf = function (day: CalendarDate): string {
  return `${day.year}-${day.month}-${day.day}`;
};

/** 取这一天的数据 */
const entriesOf = function (day: CalendarDate): readonly PopupEntry[] {
  return POPUPS[keyOf(day)] ?? [];
};

/** 不绑定数据的通用署名，拼在每条 detail 末尾 */
const createSignature = function (): HTMLElement {
  const sign = document.createElement("span");
  sign.className = "demo-popup-event-sign";
  sign.textContent = "· XX 公司";
  return sign;
};

/** 自定义 UI：一条数据返回一个完全自定义的 timeline 节点 */
const createRow = function (entry: PopupEntry, highlight: boolean): HTMLElement {
  const row = document.createElement("article");
  row.className = "demo-popup-event";

  const time = document.createElement("time");
  time.className = "demo-popup-event-time";
  time.textContent = entry.time;

  // 不绑定数据：国庆节当天的时间后面补一个表情
  if (highlight) {
    const emoji = document.createElement("span");
    emoji.className = "demo-popup-event-emoji";
    emoji.setAttribute("aria-hidden", "true");
    emoji.textContent = "🎉";
    time.append(emoji);
  }

  const title = document.createElement("strong");
  title.className = "demo-popup-event-title";
  title.textContent = entry.title;

  // 不绑定数据：只给「国庆节」这一条标题加旗子，同一天的另一条不加
  if (highlight && entry.title === "国庆节") {
    const flag = document.createElement("span");
    flag.className = "demo-popup-event-flag";
    flag.setAttribute("aria-hidden", "true");
    flag.textContent = "🚩";
    title.append(flag);
  }

  const detail = document.createElement("p");
  detail.className = "demo-popup-event-detail";
  detail.textContent = entry.detail;
  detail.append(createSignature());

  row.append(time, title, detail);
  return row;
};

const contentDay = function (day: CalendarDate) {
  // 只是示例里的额外内容，不属于 POPUPS 数据
  const highlight = day.year === 2026 && day.month === 10 && day.day === 1;
  const entries = entriesOf(day);
  if (entries.length === 0) return null;

  // 自定义 UI 每行都要建 DOM，所以把物化推迟到真正打开弹层时
  return { popup: { items: () => entries.map((entry) => createRow(entry, highlight)) } };
};

export default function CalendarUIPopupCustom() {
  let host: HTMLDivElement | undefined;
  const [picked, setPicked] = createSignal("未选择");

  onSettled(() => {
    if (!host) return;

    const instance = createCalendarUI(host, {
      initialDate: "2026-10-01",
      onSelect: (day) => setPicked(keyOf(day)),
      popup: {
        trigger: "hover",
        ariaLabel: "日期详情",
      },
      contentDay,
    });

    // 自定义示例：只在这里给日历根节点加类，CSS 由使用方自己写
    instance.el.classList.add("demo-calendar--custom");

    return () => instance.destroy();
  });

  return (
    <section class="demo-popup-panel demo-popup-panel--custom">
      <header class="demo-popup-panel-head">
        <h3>自定义 UI · 悬停触发</h3>
        <p>
          <code>items</code> 是返回 Node 数组的函数，每个 Node 带自己的类名，样式完全由使用方 CSS
          决定。
        </p>
      </header>
      <div ref={(el) => (host = el)} />
      <p class="demo-result">已选中：{picked()}</p>
    </section>
  );
}
```

## 渲染规则

内容挂在「一天的内容」上，和 badge / subtitle 是同一个返回值：

```ts
contentDay(day: CalendarDate): DayContent | null;
interface DayContent {
  badge?: CalendarBadge;
  subtitle?: string;
  ariaLabel?: string;
  data?: unknown;
  popup?: DayPopupContent;   // 存在 = 有 popup = 有绿点
}
interface DayPopupContent {
  title?: string;                                                  // 覆盖头部文案
  items: readonly DayPopupItem[] | (() => readonly DayPopupItem[]);
}
type DayPopupStringItem = readonly [time?: string, title?: string, detail?: string];
type DayPopupItem = DayPopupStringItem | Node;
```

- **内容里有 `popup` → 有绿点，点击打开**；没有或内容返回 `null` → 没有绿点；
- `contentDay` 在每次重绘时对每个可见格子调用一次（单月 42 次），所以只做「有没有」的判断；
- 内容在渲染期随内容一起产出并留在格子上，打开时直接用，**不会**再调一次 `contentDay`；
- `items` 传数组：内容已经就绪，等打开时才建 DOM；传函数：打开弹层时才调用一次，用来推迟物化；
- 数组长度就是头部显示的「几条」，一条数据对应一项；`title` 可以直接覆盖整行文案；
- 默认项是 `[time, title, detail]`，库生成 `.cui__popup-title`（`.cui__popup-time` + `.cui__popup-name`）和 `.cui__popup-detail`；
- 字段可以省略或传空字符串，对应 UI 不渲染；三个字段都为空时这一项直接忽略；
- `Node`：库只包一层 `.cui__popup-item`，内部结构和类名完全由使用方决定；可以混数据字段，也可以只放静态 HTML；Node 要在 `items` 里新建，不要跨日期复用同一个实例；
- `contentDay` / `items` 必须是同步函数，不能返回 Promise，也不要在里面发请求；数据请在 `createCalendarUI` 之前准备好；
- `popup` 选项是可选的：不写就用默认交互（click + dialog + auto 定位），内容里有 `popup` 就自动生效。

## 触发方式

```ts
trigger: "click" | "hover" | "focus" | "auto";
```

- 默认 `"click"`，点击日期时同时选中日期；
- `"hover"` 只适合桌面端只读内容，移动端没有 hover；
- `"auto"` 在支持 hover 的设备用 hover，触摸设备用 click；
- `"focus"` 用于键盘聚焦；
- 默认 click 用 `role="dialog"`，其余用 `role="tooltip"`，可用 `role` 覆盖。

## 移动端

- 用 `click` 或 `auto`，不要用 `hover`；
- 窄屏可以用 `placement: "center"` 做居中弹层，或用自己的 CSS 改成底部 sheet；
- 库已经给了 `max-height: 70vh; overflow: auto`，内容多时可以直接滚动；
- 关闭由点击外部 / `Esc` 负责，不需要额外放关闭按钮。

完整字段见 [CalendarPopupOptions](/api/calendar-ui/types/calendar-popup)。
