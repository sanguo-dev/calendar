# calendar.open

打开日历。

## 引入

```ts
import { createCalendarUI } from "@sanguo-dev/calendar-ui";

const calendar = createCalendarUI(container);
```

## 签名

```ts
calendar.open(): void;
```

## 用法

```ts
calendar.open();
```

## 参数

无。

## 返回值

`void`。

## 说明

把根节点的 `hidden` 置为 `false`，不重建 DOM、不改变选中状态。

由关闭变为打开时，会记住当时的焦点元素，供 [`close()`](/api/calendar-ui/instance/close) 默认还回去；原本就打开时不记录。
