# calendar-ui

纯 DOM、零依赖的公历日历核心。完整 API 见 [calendar-ui API](/api/calendar-ui)。

```bash
bun add @sanguo-dev/calendar-ui
```

```ts
import { createCalendarUI } from "@sanguo-dev/calendar-ui";
import "@sanguo-dev/calendar-ui/style.css";

const instance = createCalendarUI(container, {
  initialDate: "2026-10-01",
  theme: "auto",
  onSelect: (day) => console.log(day.year, day.month, day.day),
});
```

交互演示见 [calendar-ui 演示](/calendar-ui)。

## CalendarOptions

```ts
interface CalendarOptions<TData = null> {
  initialDate?: CalendarDateInput;
  minDate?: CalendarDateInput;
  maxDate?: CalendarDateInput;
  disabledDates?: readonly CalendarDateInput[];
  mode?: CalendarMode;
  months?: 1 | 2;
  animation?: CalendarAnimationOptions;
  weekStartsOn?: WeekStartsOn;
  locale?: CalendarLocale | CalendarLocaleName;
  theme?: CalendarTheme;
  size?: CalendarSize;
  header?: boolean;
  renderHeader?: HeaderRenderer;
  popup?: CalendarPopupOptions;
  adapter?: CalendarAdapter<TData>;
  subtitle?: SubtitleRenderer;
  onSelect?: (day: CalendarDay<TData>) => void;
  onRangeChange?: (range: CalendarRange) => void;
  onMonthChange?: (year: number, month: number) => void;
}

interface CalendarAnimationOptions {
  slide?: { duration?: number; easing?: string };
  collapse?: { duration?: number; easing?: string; defaultCollapsed?: boolean };
}
```

| 选项            | 类型                                   | 默认       | 说明                             |
| --------------- | -------------------------------------- | ---------- | -------------------------------- |
| `initialDate`   | `CalendarDateInput`                    | 今天       | 初始日期；越界时夹到最近可选日   |
| `minDate`       | `CalendarDateInput`                    | -          | 最小可选日期（包含）             |
| `maxDate`       | `CalendarDateInput`                    | -          | 最大可选日期（包含）             |
| `disabledDates` | `readonly CalendarDateInput[]`         | `[]`       | 禁止选中的日期                   |
| `mode`          | `"single" \| "range"`                  | `"single"` | 单选 / 范围                      |
| `months`        | `1 \| 2`                               | `1`        | 范围模式显示月数                 |
| `animation`     | `CalendarAnimationOptions`             | -          | 动画与折叠，默认全关             |
| `weekStartsOn`  | `0 \| 1`                               | `1`        | 0 周日，1 周一                   |
| `locale`        | `CalendarLocale \| "zh-CN" \| "en-US"` | `"zh-CN"`  | 界面语言                         |
| `theme`         | `"light" \| "dark" \| "auto"`          | `"auto"`   | 主题                             |
| `size`          | `"min" \| "normal" \| "fill"`          | `"normal"` | 尺寸模板：最小 / 正常 / 跟随容器 |
| `header`        | `boolean`                              | `true`     | 是否渲染头部与月份选择层         |
| `renderHeader`  | `HeaderRenderer`                       | -          | 自定义头部                       |
| `popup`         | `CalendarPopupOptions`                 | -          | 日期格 popup；不传则不启用       |
| `adapter`       | `CalendarAdapter<TData>`               | -          | 装饰适配器                       |
| `subtitle`      | `SubtitleRenderer`                     | -          | 自定义副标题，优先于 adapter     |
| `onSelect`      | `(day) => void`                        | -          | 选中日期                         |
| `onRangeChange` | `(range) => void`                      | -          | 范围变化                         |
| `onMonthChange` | `(year, month) => void`                | -          | 换月                             |

## 日期输入

```ts
type CalendarDateInput = Date | string;
```

字符串支持：

```text
2026-10-01
2026-10-1
2026/10/01
2026/10/1
```

按本地年月日解析；不存在的日期抛 `RangeError`，格式错误抛 `TypeError`。

读写字符串用两个导出的纯函数：

```ts
import { formatDate, tryParseDate } from "@sanguo-dev/calendar-ui";

formatDate("2026/10/1"); // "2026-10-01"
formatDate(day, "YYYY年M月D日"); // 格式串支持 YYYY / YY / MM / M / DD / D
tryParseDate(input.value); // 非法输入返回 null，不抛错
```

- `formatDate` 只处理年月日，时分秒会被丢弃；
- `tryParseDate` 是 `CalendarDateInput` 的不抛错版本，适合接输入框的 `input` 事件；
- 两者都额外接受 `onSelect` 里那种带 `year` / `month` / `day` 的对象。

## 日期约束

```ts
createCalendarUI(container, {
  minDate: "2026-10-05",
  maxDate: "2026-10-20",
  disabledDates: ["2026-10-12"],
});
```

- 边界包含当天；
- 边界外、禁用日期不可点击、不可键盘选中、不可被 `select()` 选中；
- 初始日期越界或被禁用时，选择最近的可选日期；
- 翻月按钮到边界月份禁用，`setMonth()` 越界夹到边界；
- `minDate > maxDate` 抛 `RangeError`；
- `disabledDates` 保持数组，不提供 predicate 函数。

## 范围选择

```ts
const instance = createCalendarUI(container, {
  mode: "range",
  initialDate: "2026-10-15",
  onRangeChange: (range) => console.log(range),
});
```

- 第一次点击起点，第二次终点；
- 终点早于起点自动交换；
- 第三次点击重新开始；
- `months: 2` 显示相邻两月，范围可跨月；
- 禁用日期不能作为端点；
- `onSelect` 仍会触发。

## 折叠

```ts
const instance = createCalendarUI(container, {
  animation: { collapse: {} },
});
```

- 不配置 `animation.collapse` 就没有底部箭头；
- 配置后默认展开，`defaultCollapsed: true` 可默认折叠；
- 折叠显示当前选中行；
- 范围折叠显示起点行和终点行；同一周只显示一行；
- 双视图每个月只显示属于该月的端点行；
- 折叠/展开只通过底部箭头操作，没有额外的实例方法。

## 主题

```ts
createCalendarUI(container, { theme: "auto" });
instance.setTheme("dark");
```

- `light` / `dark` / `auto`；
- `auto` 跟随最近的祖先 `data-theme`，没有则跟随系统；
- `setTheme()` 只改 `data-theme`，不重建 DOM。

## 尺寸

```ts
type CalendarSize = "min" | "normal" | "fill";

createCalendarUI(container, { size: "min" }); // 最小
createCalendarUI(container, { size: "normal" }); // 正常（默认）
createCalendarUI(container, { size: "fill" }); // 跟随容器宽度
```

| 模板     | 格子                   | 整块宽度      | 说明                                        |
| -------- | ---------------------- | ------------- | ------------------------------------------- |
| `min`    | 24px（有副标题 40px）  | 194px / 306px | 纯数字最小；出现副标题后整块放大一档        |
| `normal` | 46px                   | 372px         | 纯数字和带副标题一样大                      |
| `fill`   | 宽随容器，16:10 长方形 | 100% 容器     | 高度比正方形矮，副标题与休 / 班角标仍有位置 |

- `min` / `normal` 的日期格是正方形，`fill` 是 16:10 长方形；
- `min`：一旦出现过副标题就放大到 40px 格，之后不再缩回，避免翻月时整块跳动；
- `normal`：固定 46px 格，副标题多少都不改变尺寸；
- `fill`：宽度铺满容器，格子是 16:10 长方形；最窄 48px 格时整块会横向溢出，窄容器 / 双月下高度有 44px 下限，避免压掉副标题和角标；
- 双月（`months: 2`）装不下时自动上下排列，`normal` 会保持 46px 格并居中；
- 尺寸走 CSS 变量（`--cui-cell-size`、`--cui-pad`、`--cui-num-size`、`--cui-sub-size`、`--cui-tag-size` 等），可整体覆盖；
- 运行时切换：`instance.el.dataset.size = "fill"`。

## 年月选择

头部标题拆成**年份**和**月份**两个按钮，点哪个就出哪个面板，两者共用同一个下拉（从头部下方弹出，160ms 位移 + 淡入）：

- 面板尺寸由 4 列 × 3 行的格子决定，格子接近正方形，不铺满整块日历；
- 点月份：当前年的 12 个月，没有翻页按钮；选完只改月份并立即关闭；
- 点年份：12 年一页，头部两侧出现翻页按钮，按 12 年翻页；选完只改年份并立即关闭；
- 同一个按钮再点一次、点击外部或按 `Esc` 关闭；
- `minDate` / `maxDate` 之外的月份和年份自动禁用，整页越界时翻页按钮也禁用；
- 自定义头部可通过 `toggleYearPicker` / `toggleMonthPicker` 打开同一个选择层，并用 `prevDisabled` / `nextDisabled` / `pickerMode` 同步头部状态，示例见 [自定义头部](/calendar-ui/header)；
- 完全不需要头部时传 `header: false`，用实例方法或外部按钮控制月份，示例见 [无头日历](/calendar-ui/headless)。

## 动画

```ts
createCalendarUI(container, {
  animation: {
    // 传 {} 即开启，缺省 220ms / ease
    slide: { duration: 220, easing: "ease" },
    // 传 {} 即开启折叠，缺省 200ms / ease，默认展开
    collapse: { duration: 200, easing: "ease", defaultCollapsed: false },
  },
});
```

- 动画默认关闭：不传 `animation.slide` 时翻月直接切换；
- `slide: {}` → 旧月份向左/右滑出，新月份从另一侧滑入，两页连续移动；
- `collapse: {}` → 显示底部箭头，行高、透明度、间距过渡；
- `defaultCollapsed` 只对 `collapse` 生效；
- `prefers-reduced-motion: reduce` 下自动关闭；
- 可通过 CSS 变量覆盖（`--cui-month-duration`、`--cui-collapse-duration` 等）。

## subtitle

```ts
createCalendarUI(container, {
  subtitle: (day) => {
    if (day.month === 10 && day.day === 1) return "国庆";
    return null;
  },
});
```

优先级：用户 subtitle 字符串 > adapter subtitle > 空字符串。返回 `null` / `undefined` 回退 adapter，返回 `""` 明确隐藏。

## 日期格 popup

```ts
const POPUPS: Record<string, readonly PopupEntry[]> = {
  "2026-10-1": [{ title: "国庆节", detail: "10 月 1 日 - 7 日放假", time: "全天" }],
};

createCalendarUI(container, {
  popup: {
    trigger: "click",
    render: (day) => {
      const entries = POPUPS[`${day.year}-${day.month}-${day.day}`] ?? [];
      return entries.map((entry) => [entry.time, entry.title, entry.detail] as const);
    },
  },
});
```

- `render(day)` 返回 `Array<readonly [time?, title?, detail?] | Node>`；空数组表示这一天没有 popup，也没有绿点；
- `[time, title, detail]` 会生成 `.cui__popup-title` / `.cui__popup-detail` 的默认结构；字段省略或为空就不渲染对应 UI；
- 绿点由库内部按 `render(day).length > 0` 计算；
- 弹层打开时自动显示「日期 · 条数」头部，条数就是数组长度；
- `render` 在创建 / 重绘时调用并缓存，必须是同步纯函数；数据要在创建日历前准备好；
- 背景、圆角和内容排版都可以直接用 CSS 覆盖 `.cui__popup`、`.cui__popup-head`、`.cui__popup-title`、`.cui__popup-detail`；
- 完整示例见 [日期格 popup](/calendar-ui/popup)。

## CalendarInstance

| 成员                                           | 说明                       |
| ---------------------------------------------- | -------------------------- |
| `el`                                           | 根元素                     |
| `setMonth(year, month)`                        | 跳到某月                   |
| `getMonth()`                                   | 当前年月                   |
| `prevMonth()` / `nextMonth()`                  | 前后翻月                   |
| `select(date)`                                 | 选中日期                   |
| `getSelected()`                                | 单选选中；范围模式返回起点 |
| `getRange()` / `setRange()` / `clearRange()`   | 范围                       |
| `getMinDate()` / `setMinDate()`                | 最小日期                   |
| `getMaxDate()` / `setMaxDate()`                | 最大日期                   |
| `open()` / `close()` / `toggle()` / `isOpen()` | 打开 / 关闭                |
| `close(options?)`                              | 关闭并收起子层、还原焦点   |
| `getTheme()` / `setTheme()`                    | 主题                       |
| `destroy()`                                    | 销毁                       |

`close()` 是唯一的关闭入口：收起年月选择层、关闭日期格 popup、隐藏根节点，并默认把焦点还给 `open()` 之前的元素。`toggle()` 关闭时也走同一条路径，状态用 `isOpen()` 查询。

## CalendarAdapter

```ts
interface CalendarAdapter<TData = unknown> {
  readonly id: string;
  decorateMonth(input: MonthInput): ReadonlyArray<DayDecoration<TData> | null>;
}

interface DayDecoration<TData> {
  subtitle?: string;
  badge?: { text: string; tone?: string };
  data?: TData;
  ariaLabel?: string;
}
```

`decorateMonth` 每次拿到 42 个日期，返回按索引对齐的装饰数组；没有装饰返回 `null`。第三方适配器演示见 [第三方适配器](/calendar-ui/custom)。
